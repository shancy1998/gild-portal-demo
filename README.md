# GILD Portal — public static demo

This separate public repository contains only the static HTML/CSS/JavaScript demo screens. It does not contain the private project schema or backend code.

## Important

- This is a visual prototype, not a production hiring service.
- Login, registration, forms, sample jobs, and admin controls are demo-only and do not persist data.
- Do not enter real passwords, candidate details, identity numbers, or documents.
- No backend or SMS integration is hosted here. GitHub Pages serves static files only.
- Real SMS OTP would require a backend and a configured SMS provider account. Provider credentials must be stored as server-side secrets, never in this repository or an APK.

The `Deploy static demo to GitHub Pages` workflow publishes the files in this repository to GitHub Pages.
